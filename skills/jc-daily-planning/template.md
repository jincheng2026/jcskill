# 日规划输出模板（D2 极简版）

> 写入文件时按这个模板填充。
> 路径：`~/LLM-Wiki/planning/YYYY-MM-DD.md`
> 设计原则：克制、无装饰、Obsidian 渲染好看、源码也干净。

---

## 完整模板

```markdown
---
date: YYYY-MM-DD
created: HH:MM
---

# YYYY-MM-DD

> [!important] 今日大事
> ① [大事1] —— [一句话理由，说清楚为什么是大事]
> ② [大事2，如有] —— [一句话理由]

## P0

**① [事项]**（今日大事）
[障碍场景]　→　[If-Then 预案，含时间点+动作]

**② [事项]**（今日大事）
[障碍场景]　→　[If-Then 预案]

**③ [事项]**
[障碍场景]　→　[If-Then 预案]

---

**P1**　[事项] · [事项]

**砍**　[事项]（[挪到哪/砍的理由]）· [事项]（[理由]）

**搁置**　[无法解决的事，附说明]

---

## 历史延续（仅当有未完成项时）

来自 [上一份日期]：
- [留下的事] — [处理方式：继续/挪到 P0/挪到 P1]

---

## 🌙 晚上回看（手动填写）

- 今日大事是否完成？
- P0 的 If-Then 是否触发？预案是否执行？
- 明日重点：
```

---

## 格式细节（严格遵守）

### 1. Front matter
```yaml
---
date: 2026-04-29
created: 15:30
---
```
created 用 24 小时制，HH:MM 格式。

### 2. 标题
```markdown
# 2026-04-29
```
只有日期，不写"日规划"等多余字。

### 3. 今日大事 — 用 Obsidian Callout

```markdown
> [!important] 今日大事
> ① 社群预告 —— 明天最后一节，单点死线，错过窗口漏单
> ② 发 IP 视频 —— IP 启动期，断一天就断一年
```

- 用 `> [!important]` 而不是普通 `>`
- 多个大事用 ①②（圆圈数字）
- 一句话理由，不展开

### 4. P0 区 — 障碍/预案对齐

```markdown
**① 社群预告**（今日大事）
文案能写但单纯不想动手　→　If 21:00 还没动笔，发粗稿不等完美
```

**关键格式**：
- 事项名加粗 + 圆圈数字 ①②③
- 是「今日大事」的事项后面加 `（今日大事）`标记
- 障碍和预案之间用**全角空格 + → + 全角空格**：`　→　`
- 全角空格用于让箭头两边视觉留白，不需要表格

### 5. P1 / 砍 / 搁置 — 单行紧凑

```markdown
**P1**　内容复盘 · 一堂头像物料

**砍**　另一位嘉宾哥们（挪明天）· 玥亭手册（挪后天，对方不等）

**搁置**　梯子（市场原因，暂时无法解决）
```

- 用全角空格做缩进（`**P1**　`）
- 多项之间用 `·` 分隔
- 砍/搁置必须带括号说明（理由/挪到哪/为什么搁置）

### 6. 历史延续（条件性）

仅当步骤 ① 有未完成项被锦成确认"留"时才写这块。

```markdown
## 历史延续

来自 2026-04-28：
- 给生姜回复方案 — 升级到今天 P0 ②
```

### 7. 晚上回看 — 唯一的 emoji

```markdown
## 🌙 晚上回看（手动填写）
```

🌙 是整份文件唯一允许的 emoji，作为"分隔符"——白天/晚上的视觉锚点。

其他地方**禁用 emoji**。

---

## 反模式（禁止）

### ❌ 用表格代替全角空格对齐

错误：
```markdown
| 事项 | 障碍 | 预案 |
|---|---|---|
| 社群预告 | 不想动手 | 21点发粗稿 |
```

正确：
```markdown
**① 社群预告**
单纯不想动手　→　If 21:00 还没动笔，发粗稿不等完美
```

理由：表格在 Obsidian 里渲染过于结构化，破坏阅读流。全角空格更轻盈。

### ❌ 在 P0 事项加多余 emoji

错误：
```markdown
**🔴 ① 社群预告 ⚡️**
```

正确：
```markdown
**① 社群预告**（今日大事）
```

### ❌ 用花线 / 装饰性分隔

错误：
```markdown
═══════════════════
✨ P0 必做 ✨
═══════════════════
```

正确：
```markdown
## P0
```

### ❌ Why/How 等多层结构展开

错误：
```markdown
**① 社群预告**
- Why: ...
- How: ...
- When: ...
- Obstacle: ...
- If-Then: ...
```

正确：
```markdown
**① 社群预告**（今日大事）
单纯不想动手　→　If 21:00 还没动笔，发粗稿不等完美
```

理由：D2 哲学是**信息密度高但视觉克制**。一行说清楚的事不分多行。
