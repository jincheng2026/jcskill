# 写稿反馈记录

AI 陪你写稿时，遇到下面这些情况会往这一页最后追加一条：你明确说了哪里好、哪里不好；你亲手改了稿或纠正了 AI 对原因的理解；试读、录制、剪辑时暴露了内容问题；你确认了定稿，或者给了发布数据。纯提问和你没接受的 AI 建议不记。

只往后追加，不改旧记录。新反馈推翻旧理解时，追加一条校正。复盘和改 Skill（jc-skill-writer）时把这里当证据读。

格式：

```
## YYYY-MM-DD｜T001 选题名

- 阶段：叙事 / 脚本 / 拍摄 / 剪辑 / 成片 / 发布数据
- 你的原话：
- 这次改了什么：
- AI 对原因的理解：写明「你确认过」或「AI 归纳」，AI 归纳要列依据
- 结果：待观察 / 有效 / 无效
```
