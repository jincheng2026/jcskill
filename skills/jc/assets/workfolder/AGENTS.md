# 给 AI 的说明：这个文件夹怎么用

这里是做内容的工作文件夹：选题、草稿、市场调研、发布档案都放在这里。JC 内容创作系列 Skill（jcskill 仓库里的 jc、jc-media-research、jc-benchmark-intake、jc-video-analysis、jc-jiaocheng-video、jc-zhuanxie、jc-gongzuotai-write、jc-jianjie、jc-koubo-shuping、jc-publish-closeout、jc-media-review、jc-skill-writer）和开源的「创作工作台」（jincheng-workbench）用的是同一个文件夹、同一套布局。装了工作台时，工作台网页只读这里的文件；你（AI）改了文件，用户切回工作台点「重新读取」就能看到。没装工作台时，下面提到工作台网页、工作台 Skill 的地方，照「JC 系列」一节换成对应的 jc Skill 做。

## JC 系列多用的几处

| 放什么 | 位置 | 谁写 |
| --- | --- | --- |
| 对标素材：一条作品一个文件夹（原文、媒体、校正版逐字稿和同名时间码字幕） | `市场调研/对标素材/未参考/<平台>/`，实际支撑过一条正式内容的挪到 `市场调研/对标素材/已参考/<平台>/` | jc-benchmark-intake |
| 你的口气样本 | `写稿方法/08_我的口气样本.md` | 你自己放，或定稿后 AI 整理、你同意才写 |
| 写稿反馈记录 | `写稿方法/反馈记录.md` | jc-jiaocheng-video（只追加） |
| 发布后的档案：一条视频一个文件夹 | `已发布/YYYY-MM-DD-标题/`（`内容.md`、封面、`数据.jsonl`） | jc-publish-closeout 建档和抓数据，jc-media-review 写复盘 |
| 已发布总览：一条视频一行 | `已发布/00_已发布总览.md` | jc-publish-closeout |

没装工作台时：加选题照下面「加一条选题（三处都要做）」手动三步做；创作页用 jc-gongzuotai-write（它会先把工作台装好）；调研用 jc-media-research；封面用工作台仓库里的 jincheng-workbench-cover。

## 每类东西放在哪

| 放什么 | 位置 |
| --- | --- |
| 选题总览：全部选题一张表 | `选题库/00_选题总览.md` |
| 选题卡：每条选题一张 | `选题库/<类型>/待做/`，做完挪到 `选题库/<类型>/已做/` |
| 草稿：每条内容一个文件夹 | `内容草稿/T001_选题名/` |
| 创作页：每条内容一个，放在它的草稿文件夹里 | `内容草稿/T001_选题名/T001_创作页.html` |
| 封面候选：每条内容出的候选封面，放在它的草稿文件夹里 | `内容草稿/T001_选题名/封面候选/`，选定的那张是 `T001_选题名/封面-选定.png` |
| 写稿方法：用户自己的写法和判断 | `写稿方法/` |
| 对标账号：每个账号一个文件夹 | `市场调研/对标账号/<平台>-<账号名>/` |
| 调研报告：每份报告一个文件夹 | `市场调研/调研报告/<日期_主题>/` |
| 社媒助手导出的评论 | `市场调研/评论导入/` |
| 提示词：一条一个 md 文件 | `提示词/<分类>/名字.md` |
| 封面素材：人物参考图片（用户自己的照片）、用户放进来的几组封面图、封面设置 | `封面素材/` |
| 不要了的文件 | `回收站/`（不要直接删除） |

内容类型现在是 「教程」、「科普」、「口播」，每一类在选题库里有一个同名文件夹。类型是在工作台的设置文件里定的，要加减类型先改设置，再在选题库里建对应的文件夹、在选题总览里加对应的「### 类型」一节。

## T 编号

- 每条选题一个编号：T 加三位数字，从 T001 开始往下排。
- 编号定了就不改、不复用；作废的选题，编号也不再给别的选题。
- 新编号 = 选题总览里最大的编号加一。

## 加一条选题（三处都要做）

用写稿 Skill（jincheng-workbench-write）里「加选题」的做法加：编号、加在选题总览哪一格、选题卡都由工作台仓库里的 `scripts/add-topic.mjs` 写，不会编错号、加错格。没有这个 Skill 时照下面三步手动加。

1. 在选题总览「## 选题总表」下面、对应类型的「**待做**」表里加一行：编号、选题、来源、状态（新选题写「待写」），发布日期和效果先空着。
2. 在 `选题库/<类型>/待做/` 里建选题卡，文件名「编号_选题名.md」，格式照下面。
3. 开始写稿时，在 `内容草稿/` 里建「编号_选题名」文件夹，稿子都放进去。

## 选题总览的格式

- 表头固定是：| 编号 | 选题 | 来源 | 状态 | 发布日期 | 效果 |
- 状态只写：待写 / 草稿 / 已发布。
- 录完或拍完的，选题前面加 ✅，这一行挪到同一类的「**已做**」表；选题卡也从 `待做/` 挪到 `已做/`，标题编号后面加 ✅。
- 「## 近三天内容安排」表（日期 | 安排 | 对应选题）和「## 顺延事项」表（安排 | 新日期 | 对应选题）可以不填；对应选题里写编号。

## 选题卡的格式

```
# T001 选题标题

- **来源**：自己的想法 / 参考别人 / 混合
- **状态**：待写
- **发布日期**：
- **效果**：

## 选题内容

写给谁、解决什么问题、大概怎么讲。
```

选题卡顶部这几行和选题总览那一行要一致；改一处，另一处一起改。

## 草稿文件夹里的文件怎么起名

工作台按文件名认出每份文件是什么：

- 名字里有「工作稿」「初稿」「逐字稿」：正在写的稿子，工作台的「接着写」会打开最近改过的那份。
- 名字里有「定稿」「最终稿」「录制版」：定稿；有「提词器」：提词器版。这两类在详情页可以一键复制全文。
- 名字里有「改稿日志」：改稿记录。
- 旧版本放进草稿文件夹里的「版本」子文件夹，工作台只数个数，不一条条列出来。
- 稿子用 .md 或 .txt；图片、视频也可以放，工作台只数个数。

## 写稿和创作页

- 写稿、给改稿建议之前，先读 `写稿方法/` 里的文件：那是用户自己的写稿方法，用户改了就按新的来。文件还写着「待填」的，按写稿 Skill 里最基本的做法来。
- 第一版逐字稿写好后，用写稿 Skill（jincheng-workbench-write）把它做成创作页：`内容草稿/T001_选题名/T001_创作页.html`。用户在页面上直接改稿，改动自动存回这个文件；工作台「内容」栏的详情页能一键打开它。
- 创作页只用写稿 Skill 里写的命令读和改（工作台仓库里的 creation-page/brain_page.py），不要用编辑工具直接改这个 HTML 文件，也不要复制它做备份。
- 以 . 开头的 `.jc-locks`、`.jc-versions`、`.jc-changes` 是创作页自动留的锁、备份和改动记录，不要动。

## 市场调研

- 对标账号、调研报告、评论导入三个文件夹放什么、文件格式是什么，写在 `市场调研/README.md` 里，动手前先读它。
- 调研（拉博主的作品和数据、分析评论区、出调研报告）用调研 Skill（jincheng-workbench-research）。
- TikHub 的 key 只存在这台 Mac 的钥匙串里，不要写进任何文件，也不要打印出来。

## 封面

- 拆封面 VI（对标博主的，或者用户放进来的几张图）、给一条选题出一批封面、按用户的评论改一张、记下用户定了用哪张，都用封面 Skill（jincheng-workbench-cover）：人物参考图片、风格、编号、生成记录都由它的脚本读写，文件放在哪也写在它里面。
- 用户自己的照片放在 `封面素材/人物参考图片/`（工作台上也叫「人物参考图片」），放一张或几张，一张封面最多参考排在前面的 3 张；默认照哪个风格做，记在 `封面素材/封面设置.json`。对标博主的封面图和 VI 拆解放在他的对标账号文件夹里；用户放进来的几组图在 `封面素材/风格/` 下面，一组一个文件夹。
- 候选封面一直往后编号（封面-01、封面-02……），不覆盖、不复用；按评论改一张，也存成新的一张。
- 挑一张、改一张在 Codex 桌面版里做：用户点开生成的图，在 Canvas 里用 Comment 标出要改的地方发给你；用户说了「就用 03」，才把那张存成草稿文件夹里的「封面-选定」。工作台「内容」栏的「封面」页和每条选题的页面只用来看，不改封面。

## 提示词的格式

一条提示词一个 .md 文件，放在哪个子文件夹就属于哪个分类。文件开头用三条横线包住几行说明，下面是要复制的正文：

```
---
title: 卡片上显示的名字
when: 什么时候会想起它，用自己当时会说的话写
summary: 一句话说清它会做什么
tags: 可选，多个用顿号分开
source: 可选，来自哪里
---
提示词正文。要每次填写的地方写成 {{名称}}，复制前工作台会先让你填。
```

文件名以 _ 开头的不会被当成提示词：`_格式说明.md` 是说明，`_分类顺序.md` 定分类的先后，`_排序.md` 是工作台记的卡片顺序，`_使用记录.jsonl` 是工作台记的复制和收藏记录。后两个由工作台维护，不要手改。

## 规矩

- 不要直接删除任何文件；不要的东西挪进 `回收站/`，文件名前面加上日期，比如「2026-01-01_原文件名」。
- 不要改已有的编号，不要重排编号。
- 不确定一条选题属于哪个类型时，先问用户。
