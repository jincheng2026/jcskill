# 搜索和筛选

## 记录搜索计划

每次搜索都保存：

- 研究问题。
- 平台和内容类型。
- 关键词组及扩展理由。
- 排序方式。
- 首选时间范围和实际时间范围。
- 每页数量、计划页数、最高请求数。
- 去重键。
- 合格条件和停止条件。

## 扩关键词

从用户原词出发，只增加与研究问题有关的词：

1. 产品名和常见别名。
2. 具体功能。
3. 用户正在解决的问题。
4. 想得到的结果。
5. 目标人群和使用场景。
6. 同类产品或替代做法。

每个扩展词保留来源和理由。不要为了增加样本量加入宽泛热词。

## 抖音 AI 教程默认门槛

先按硬门槛判断，再排序：

```text
platform == douyin
100 <= follower_count <= 20000
digg_count >= 1000
relevance == direct
```

最近 90 天只决定优先级，不降低粉丝、点赞或相关性门槛。

把未合格样本分开保存：

- `anomaly_low_followers`：少于 100 粉，可观察但不并入默认样本。
- `regular_viral_reference`：超过 20,000 粉，可作普通爆款参考。
- `unverified_low_likes`：少于 1,000 赞，不叫已验证爆款。
- `adjacent`：相邻主题，只用于扩展理解。
- `off_topic`：无直接关系，排除。
- `missing_evidence`：缺少粉丝、点赞、来源或相关性证据。

不要降低门槛补齐「10 条」。只有 3 条合格，就直接报告 3 条；0 条时直接报告 0 条。说明已经扩过哪些关键词、排序和时间，不降低门槛，也不要求用户确认这个数量或重新选择样本。

## 相关性判断

每条内容必须有一个相关性标签和一句证据理由：

- `direct`：内容主体直接解决当前研究问题。
- `adjacent`：与人群或场景相关，但主体不是当前问题。
- `off_topic`：只有词面碰巧出现，或主题无关。
- `unknown`：现有标题、正文或字幕不足以判断。

只有 `direct` 能进入默认低粉爆款集合。AI 根据现有内容完成语义判断和筛选，并写出一句可核对的理由；用户可以在结果交付后改判，改判记录为用户确认，不在执行中设置确认门。

## 去重和快照

- 首选平台内容 ID 作为去重键。
- 没有 ID 时，使用规范化来源 URL；仍没有时标为证据不足。
- 同一内容多次出现时保留每次快照，不静默覆盖。
- 输出代表记录时说明使用最新快照还是首次快照。
- 当前粉丝数是采集时快照，不推断发布时粉丝数。

## 排序

只在合格样本中使用透明排序，例如：

1. 点赞数。
2. 收藏数。
3. 分享数。
4. 评论数。

需要计算赞粉比时同时展示原始点赞和粉丝数，不单独用比值证明爆款。分母太小的异常样本不得混入正常排序。

完整研究需要继续深挖时，在合格样本内部先按最近 90 天优先，再结合直接相关性和点赞、收藏、分享等透明指标自动选择最多 3 条。报告中说明选择依据，不让用户先回复「选哪条」才继续。

## 跨平台边界

不同平台的粉丝、播放、点赞、收藏和评论口径不同。没有经过用户确认和真实样本验证，不把抖音门槛直接套到其他平台，也不把不同平台指标放在同一坐标轴比较。

## 账号自身基线

先保留每次采集的原始快照。代表记录按平台、content_id、collection_batch_id 去重，同一批次优先使用更新且完整的记录。没有批次信息的旧数据不推定属于同一次采集。

默认分组为 platform + author_id + content_type + collection_batch_id。昵称不是稳定标识；同名作者不能合组。任一字段未知时倍率为空，并列出缺失字段。每组指标一致：只有组内播放量均有值且明确可靠时采用 view_count，否则采用 like_count；平台常见的占位 0 播放不能自行标为可靠。

以明确的 as_of 为研究时点，取近 90 天、发布满 7 天、排除目标自身后最新 30 条；这 30 条中至少 10 条指标有效。缺失指标不补 0，也不向更旧作品补足到 30 条。中位数为 0、有效样本不足或目标指标缺失，ratio 为 null 并记录原因。新作品仍可作为选题候选，但标明尚未成熟，不用未成熟作品充当普通对照。

报告逐条展示原始指标、基线指标、中位数、样本数、样本 ID、倍率、采集时粉丝数、粉丝快照日期、发布日期和类型。倍率用于决定优先研究谁，不是原创性、质量或因果评分。低粉爆款硬门槛仍单独保留。

## 高表现与普通作品选样

research_decisions.py select 每组默认选 1 条可计算且高于自身基线的成熟作品，再从该作品的基线样本池取 2 条最接近其中位数的普通作品。来源不足如实报告，不用低质量样本补位。同题其他作者最多 2 条，必须有明确相同 topic_id、平台和类型，并核对实际原文相关性及发布时间。

选样 JSON 是阅读清单，不是分析成品。Agent 阅读正文后补齐主题、开头、推进、证明、画面、评论六项对照。标题只支持标题层观察；缺逐字稿、画面或评论的维度标 unknown。采集日与作品年龄不同、粉丝变化、题材热度、流量分发、封面和其他未控制条件都可能解释表现差异。
